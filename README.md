# SpendWise - JavaScript Foundation

## Project Description

SpendWise is a simple budget and expense tracking application designed to help users manage their budgeting information.

The application allows users to enter their total budget and total expenses using native HTML form inputs. JavaScript validates the information, converts the input into numbers, performs the budget calculation, updates the webpage, and displays a clearly labeled report in the browser console.

This project builds on the visual SpendWise application by adding JavaScript functionality and making the application interactive.
