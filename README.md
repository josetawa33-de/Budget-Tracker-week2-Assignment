# SpendWise - JavaScript Foundation

## Project Description

SpendWise is a simple budgeting application designed to help users understand their budget, expenses, and remaining balance.

This version of SpendWise uses JavaScript to collect user information, perform calculations, and display budgeting results.

## JavaScript Concepts Implemented

The project demonstrates the following JavaScript concepts:

- Variables
- Data types
- User input
- Number conversion
- Calculations
- Functions
- DOM manipulation
- Console output
