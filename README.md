# SpendWise - Week 6

## Make SpendWise Interactive

SpendWise is a personal budget and expense tracking web application built using HTML, CSS, and JavaScript.

The purpose of this Week 6 project is to improve the previous SpendWise application by adding JavaScript interactivity. Users can set a budget, add expenses, select categories, view their total expenses, calculate their remaining balance, delete expenses, and clear all expenses.

---

## Project Features

The Week 6 version of SpendWise includes:

- Set a personal budget.
- Add expenses.
- Select an expense category.
- Record small and large expenses.
- Calculate total expenses automatically.
- Calculate the remaining balance.
- Display the number of expenses.
- Delete individual expenses.
- Clear all expenses.
- Validate user input.
- Display success and error messages.
- Warn users when expenses exceed their budget.
- Dynamically update the webpage.
- Responsive design for desktop, tablet, and mobile screens.
