# My Budget Tracker

## Project Description

My Budget Tracker is a simple web page designed to help users record and view their expenses. The project focuses on creating a clean, attractive, and user-friendly interface using HTML and CSS.

The project contains two main files:

- `index.html` — Provides the structure and content of the Budget Tracker.
- `style.css` — Controls the visual design, layout, colors, fonts, spacing, borders, and hover effects.

## Files

### 1. index.html

The `index.html` file contains the main structure of the Budget Tracker webpage.

It includes:

- The page title **My Budget Tracker**
- A subtitle explaining the purpose of the tracker
- An **Add Expense** form
- An item input field
- An amount input field
- A category selection field
- An **Add Expense** button
- An **Expense Table** displaying sample expenses
- A budgeting video section at the bottom of the page

HTML is used to organize the content and create the elements that appear on the webpage.

## 2. style.css

The `style.css` file controls the visual appearance of the Budget Tracker.

It includes:

- A light-blue page background
- Pink card sections
- Rounded corners
- Shadows for a modern card design
- Montserrat and Roboto Google Fonts
- Styled headings and subtitles
- Styled input fields and dropdown menus
- A modern blue button
- Styled table headers and table rows
- Alternating table row colors
- Hover effects on cards, buttons, inputs, table rows, and the video
- Responsive design for smaller screens

The CSS uses the box model through **margin, padding, borders, width, and border-radius** to create a clean and organized layout.

## Design Features

### Color Palette

The project uses:

- Light blue for the page background
- Light pink for the main sections
- Dark blue for headings and table headers
- White for input fields and table backgrounds
- Blue for the main button and interactive elements

These colors provide a clear and professional appearance.

### Typography

The project uses two Google Fonts:

- **Montserrat** for headings and buttons
- **Roboto** for normal text and form fields

This creates a clear visual difference between headings and body content.

### Hover Effects

Interactive hover effects have been added to improve the user experience.

Examples include:

- Cards lift slightly when hovered
- The logo becomes larger and rotates slightly
- Buttons change color and lift when hovered
- Input fields highlight when hovered
- Table rows highlight when hovered
- The video section becomes slightly larger when hovered

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- YouTube Embed

## Project Purpose

The purpose of this project is to practice HTML and CSS skills by designing a visually appealing Budget Tracker interface. The project demonstrates the use of colors, typography, the CSS box model, tables, forms, responsive design, and interactive hover effects.
